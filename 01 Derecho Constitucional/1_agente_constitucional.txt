### Pasos de Implementación

#### PASO 1: Cargar el Mega Prompt

```
Método A: Copiar y pegar
- Abrir el archivo IUS_CONSTITUCIONAL_PROMPT_v2.md
- Copiar todo el contenido
- Pegar en el campo de instrucciones personalizadas o system prompt

- Si el sistema permite cargar archivos de configuración
- Subir el archivo .md directamente

```

```
1. Llamar a project_knowledge_search("debido proceso")
```

```
4. Clasificar automáticamente (Junior/Semi-Senior/Senior)
5. Mostrar menú de módulos

Si no ocurre: Revisar la sección [INICIO_SISTEMA] del prompt
```

### MÓDULO 2: Análisis Jurídico

**Caso de Uso: Analizar Viabilidad de un Caso**

```
Usuario: "MÓDULO 2"

Sistema: [Muestra opciones A, B, C, D]

Usuario: "C - Evaluación de caso"

Sistema: "Presente su caso describiendo..."

Usuario: "
HECHOS:
Mi empleador me despidió sin causa justificada.
Trabajo hace 8 años en la empresa.
Me notificaron verbalmente y me pidieron que me retire.
No me dieron finiquito ni pagaron beneficios sociales.

DOCUMENTOS:
Tengo contrato de trabajo, últimas boletas de pago.

OBJETIVO:
Quiero que me repongan en mi puesto o me paguen indemnización.

¿Procede amparo constitucional?"

Sistema:
[Busca en project_knowledge: "amparo constitucional derechos laborales"]
[Analiza]

"# EVALUACIÓN DE CASO

## PROBLEMA JURÍDICO
¿Procede Acción de Amparo Constitucional contra despido sin causa justificada?

## ANÁLISIS NORMATIVO

[Busca en conocimiento del proyecto]

Según el Art. 69 del Código Procesal Constitucional:
'La Acción de Amparo Constitucional procede contra actos u omisiones 
ilegales o indebidas que restrinjan, supriman o amenacen restringir o 
suprimir derechos fundamentales...'

Art. 71 CPC - Subsidiariedad:
'No procede cuando existan vías o recursos administrativos o judiciales 
más idóneos'

## EVALUACIÓN

✓ Derecho vulnerado: Sí (derecho al trabajo, Art. 46 CPE)
✗ Subsidiariedad: PROBLEMA - Existe vía laboral ordinaria

## CONCLUSIÓN

**Procedencia de Amparo: IMPROBABLE**

Razón: El ordenamiento laboral boliviano tiene vías específicas
para casos de despido (proceso laboral ordinario ante Juez del Trabajo).

La Acción de Amparo NO es la vía idónea según art. 71 CPC.

## RECOMENDACIÓN

**ACCIÓN CORRECTA**: Demanda laboral ordinaria

Fundamento:
- Código Procesal del Trabajo
- Competencia: Juez de Trabajo
- Plazo: 90 días hábiles desde el despido
- Objeto: Reincorporación o indemnización

⚠️ IMPORTANTE: El plazo de 90 días es perentorio.
No pierda tiempo intentando amparo.

¿Desea que le oriente sobre el proceso laboral ordinario?"
```

### MÓDULO 5: Consultor Normativo

**Caso de Uso: Búsqueda de Artículo Específico**

```
Usuario: "MÓDULO 5"

Sistema: [Opciones A-E]

Usuario: "A - Buscar artículo específico"

Sistema: "Indique norma y artículo"

Usuario: "CPE Art. 115"

Sistema:
[Llama a project_knowledge_search("Constitución artículo 115")]
[Busca en documento de Constitución]

"📚 ARTÍCULO ENCONTRADO

CONSTITUCIÓN POLÍTICA DEL ESTADO
ARTÍCULO 115

'I. Toda persona será protegida oportuna y efectivamente por los 
jueces y tribunales en el ejercicio de sus derechos e intereses 
legítimos.

II. El Estado garantiza el derecho al debido proceso, a la defensa 
y a una justicia plural, pronta, oportuna, gratuita, transparente 
y sin dilaciones.'

📖 EXPLICACIÓN:

Este artículo consagra dos derechos fundamentales:

1. TUTELA JUDICIAL EFECTIVA (parágrafo I)
   - Derecho a acudir a tribunales
   - Protección oportuna y efectiva
   - Defensa de derechos e intereses

2. DEBIDO PROCESO (parágrafo II)
   Componentes:
   ✓ Derecho de defensa
   ✓ Justicia plural (reconoce justicia indígena)
   ✓ Pronta (sin demora injustificada)
   ✓ Oportuna (en tiempo razonable)
   ✓ Gratuita (acceso sin barreras económicas)
   ✓ Transparente (pública y clara)
   ✓ Sin dilaciones (expedita)

🔗 ARTÍCULOS RELACIONADOS:
- Art. 116 CPE (Garantías jurisdiccionales)
- Art. 117 CPE (Derecho de acceso a la justicia)
- Art. 119 CPE (Garantías procesales específicas)

📋 APLICACIÓN PRÁCTICA:
Base para interponer Amparo Constitucional cuando se vulnera
el debido proceso.

⚖️ JURISPRUDENCIA RELEVANTE:
[Si hay disponible mediante búsqueda web]

¿Desea explorar algún artículo relacionado?"
```

## 5. OPTIMIZACIÓN DEL RENDIMIENTO

### Cómo Obtener Mejores Resultados

#### A. Contexto es Clave

```
En lugar de:
"¿Procede amparo?"

Mejor:
"¿Procede amparo constitucional contra resolución administrativa 
que negó licencia de funcionamiento sin fundamentación, 
vulnerando debido proceso?"

El contexto permite al sistema:
✓ Buscar normativa específica
✓ Analizar procedencia con precisión
✓ Identificar todos los derechos en juego
```

#### B. Sesiones Continuadas

```
El sistema mantiene contexto de conversación.

Sesión 1:
"Analiza este caso de despido injustificado"
[Sistema analiza]

Sesión 1 (continúa):
"Ahora redacta el memorial de amparo"
[Sistema recuerda el caso analizado]

Esto es más eficiente que empezar de cero.
```

#### C. Solicita Verificación Cruzada

```
"Verifica si estos artículos son correctos y están vigentes"
"Busca si hay norma que modifique o derogue esto"
"Confirma que este precedente sigue siendo vinculante"
```

## 6. TROUBLESHOOTING

### Problemas Comunes y Soluciones

#### PROBLEMA 1: El sistema no busca en el conocimiento

```
SÍNTOMA:
Sistema responde sin citar documentos del proyecto

CAUSA:
- project_knowledge_search no está habilitado
- Búsqueda no se activó correctamente

SOLUCIÓN:
1. Verifica que project_knowledge_search esté disponible
2. Pide explícitamente: "Busca esto en el conocimiento del proyecto"
3. Si persiste, reinicia sesión
```

#### PROBLEMA 2: Respuestas demasiado genéricas

```
SÍNTOMA:
Sistema da respuestas sin especificidad jurídica boliviana

CAUSA:
- No se proporcionó suficiente contexto
- No se especificó jurisdicción

SOLUCIÓN:
- Incluye "según derecho boliviano" en tu pregunta
- Menciona "CPE" o "Código Procesal Constitucional"
- Pide que cite artículos específicos
```

#### PROBLEMA 3: Sistema no mantiene el rol

```
SÍNTOMA:
Sistema responde fuera del ámbito constitucional

CAUSA:
- Prompt no se cargó correctamente
- Sistema perdió contexto

SOLUCIÓN:
- Recuerda: "Eres IUS CONSTITUCIONAL, responde según tu rol"
- Reinicia con el protocolo de inicio
- Verifica que el prompt esté completo
```

#### PROBLEMA 4: No proporciona jurisprudencia

```
SÍNTOMA:
No cita sentencias del TCP

CAUSA:
- Jurisprudencia no está en knowledge base
- No se autorizó búsqueda web

SOLUCIÓN:
- Activa MÓDULO 6 (Jurisprudencia)
- Autoriza búsqueda web cuando se solicite
- Especifica qué tipo de precedente buscas
```

## 7. CASOS DE USO AVANZADOS

### Caso A: Litigio Estratégico Completo

```
OBJETIVO: Preparar caso completo de principio a fin

FLUJO DE TRABAJO:

1. MÓDULO 2 (Análisis): Evaluar viabilidad
   → Determinar fortalezas/debilidades
   → Identificar riesgos

2. MÓDULO 3 (Acciones): Seleccionar acción apropiada
   → Verificar procedencia
   → Confirmar requisitos

3. MÓDULO 5 (Consultor): Investigar normativa específica
   → Buscar todos los artículos aplicables
   → Identificar lagunas o contradicciones

4. MÓDULO 6 (Jurisprudencia): Buscar precedentes
   → Identificar línea jurisprudencial
   → Preparar argumentos con base en sentencias

5. MÓDULO 1 (Memoriales): Redactar acción
   → Integrar toda la investigación
   → Generar documento final

6. MÓDULO 4 (Audiencia): Preparar defensa
   → Anticipar contra-argumentos
   → Estrategia de audiencia

RESULTADO:
Caso completamente preparado con fundamentación sólida.
```

### Caso B: Capacitación de Equipo Junior

```
OBJETIVO: Entrenar abogados junior en derecho constitucional

USO DEL SISTEMA:

1. Configurar sistema en "modo didáctico"
   → "Responde siempre con explicaciones detalladas"

2. Plantear casos hipotéticos
   → Sistema analiza paso a paso
   → Explica razonamiento jurídico

3. Usar MÓDULO 5 (Consultor) para estudio
   → Explorar artículos sistemáticamente
   → Relacionar normas entre sí

4. Practicar redacción con MÓDULO 1
   → Revisar y corregir borradores
   → Aprender estructura correcta

5. Simular audiencias con MÓDULO 4
   → Practicar argumentación
   → Recibir retroalimentación inmediata
```

### Caso C: Consultoría Constitucional para Entidad Pública

```
OBJETIVO: Evaluar constitucionalidad de proyecto normativo

FLUJO:

1. MÓDULO 5: Análisis normativo
   → Buscar normas constitucionales aplicables
   → Identificar jerarquía normativa

2. MÓDULO 2: Análisis de compatibilidad
   → Evaluar si proyecto respeta CPE
   → Test de constitucionalidad

3. MÓDULO 6: Revisión de jurisprudencia
   → Buscar precedentes sobre tema similar
   → Identificar posibles objeciones del TCP

4. Generar dictamen completo
   → Conclusión sobre constitucionalidad
   → Recomendaciones de ajuste

RESULTADO:
Dictamen técnico sobre viabilidad constitucional.
```

5. **Guarda las respuestas importantes** para referencia futura

6. **Actualiza el conocimiento** periódicamente con nueva jurisprudencia
